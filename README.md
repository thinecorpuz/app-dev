# 🎬The Platform (2019)
 
> — **The Platform**

##  Overview
**The Platform** (_El Hoyo_) is a **Spanish science fiction psychological thriller** directed by **Galder Gaztelu-Urrutia**. Released in **2019**, the film is set in a **vertical prison** where food is delivered via a descending platform, creating a brutal hierarchy of survival.

## 🧠Plot Summary
In a dystopian future, inmates are housed in a tower-like structure called the **Vertical Self-Management Center**. Each level contains two prisoners. A platform filled with food descends from the top, stopping briefly at each level. Those at the top eat well, while those below starve or fight for scraps. Every month, prisoners are randomly reassigned to a new level, forcing them to adapt to drastically different conditions.
